function deriveKey(): Buffer {
  const secret = process.env.NEXTAUTH_SECRET || 'cell-fallback-secret-change-me';
  // 32-byte key from the app secret
  return crypto.createHash('sha256').update(String(secret)).digest();

If NEXTAUTH_SECRET is unset, deriveKey() returns sha256 of a constant that
is present in the public source. Every deployment in that state shares one
AES-256-GCM key, so anyone holding the ciphertext blobs can decrypt every
user's stored provider API key. The blobs are the encrypted-at-rest column
this module exists to protect.
