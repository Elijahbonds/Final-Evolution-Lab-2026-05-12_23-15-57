# Concept Lock — Beach Sprint

**Benchmark:** Track & Field rhythm sprint — reaction, cadence, false starts,
and the dip at the tape. The file header says the race is the shared SprintCore
with its tuned constants carried over untouched.

**Mode id:** `sprint` · **Implementation:** `lib/babylon/modes/SprintMode.ts`
· **Route:** `/play/sprint`

## Criteria

| # | Criterion | Status |
|---|---|---|
| A1 | READY / SET / GO start gate with real false starts | Locked |
| A2 | Alternating left/right cadence is the race, not mashing any button | Locked |
| A3 | Reaction time is measured and called out | Locked |
| A4 | A rival pacer gives the lane pressure | Locked |
| A5 | Up on the D-pad is a late dip, only near the tape | Locked |

## Deviations

Buttons deliberately refuse with "THE D-PAD RUNS" because the D-pad cadence is
the benchmark's skill expression.
